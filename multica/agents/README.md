# Multica agent templates

No production Multica agent definition existed in the source repository at this migration point. Codex TOML profiles under `.codex/agents/` are different objects.

For a new Multica agent, review its name, instructions, intended skills, access, and runtime provider here. On each installation, authenticate with the pinned CLI or UI, select that machine's registered runtime, create or update the agent, and assign workspace skills and MCP entries. Keep runtime IDs and custom environment values local.
